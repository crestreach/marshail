# MARSHAIL v1.1.0

*Real subagent dispatch, per-agent model pinning, and a more human implementation cycle.*

A feature release focused on making agent orchestration and configuration more explicit and controllable, alongside a small round of documentation clarity fixes.

## What changed

- **Real subagent spawning is now required, not emulation.**
  Agents were sometimes emulating stage agents inside the caller's context instead of spawning them.
  The activation protocol now states this explicitly: prefer the delegate skill flavor whenever a subagent-spawn tool exists; fall back to inline emulation only when no such tool exists.
  `marshail-driver` dispatches stage agents by spawning, never inline, and "re-dispatching" now means re-invoking the subagent, not re-implementing the stage.
- **New `agent-models.yml`.**
  Lets a repo pin a specific model per agent (e.g. a stronger model for the architect or planner, a cheaper one for the helper).
  `marshail-promote-assets` writes the assignment as the promoted agent's `model` frontmatter key; tools without per-agent model support ignore it.
  Seed-once, like `marshail-override.md` and `agent-tools.yml` — never overwritten on update.
- **`agent-tools.yml` is now actually installed.**
  The per-agent tool-grant file was documented but never placed by the installer, so consumer repos had nothing to fill in.
  The installer now seeds the shipped template (empty mapping plus commented examples) on a fresh install and never clobbers it on update.
- **Human inspection and feedback are now an explicit part of the implementation cycle.**
  Each cycle lets the human inspect intermediate results and give feedback at any point; feedback is applied before the cycle closes rather than treated as an interruption.
  Hands-off runs may skip inspection and rely on the Verify stage and approval gates instead.
- **Knowledge files now document their cross-references.**
  Related topics, decisions, and indexes are linked instead of duplicated, so an agent can follow a reference only when it needs it.
- **Small clarity fixes.**
  A pronunciation note for MARSHAIL was added to the README and `marshail.md`; the `agent-tools.yml` vs `agent-models.yml` wording in the README was clarified.
- **Cyncia updated to v1.1.6.**

## Upgrade notes

No breaking changes.
Re-run the installer to pick up the newly-seeded `agent-tools.yml` template (only written if missing) and to update cyncia to v1.1.6.
Existing `agent-tools.yml` or `agent-models.yml` files, if you already created them by hand, are left untouched.

## Install

From the root of your target repo:

```bash
curl -fsSL https://raw.githubusercontent.com/crestreach/marshail/main/scripts/install-marshail.sh | bash
```

Then run the `marshail-init` skill once to integrate MARSHAIL into the repo.
